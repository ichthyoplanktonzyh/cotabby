## 实验与结果

本次使用 Release app-hosted 的生产原生控制器、模板与解析器，现有 Gemma 4 E4B Q4_K_M 权重。11 个固定原文/译文对，各提示词重复两轮，共 44 次正式请求；预热单独记录，不进入正式耗时。两组交替先后顺序，共用已加载模型、0.3 temperature / 0.9 top_p / 40 top_k / 4096 输出预算；生产随机种子未人为控制。每次新生成序列，失败也写入报告，不修复输出或丢弃分母。

对照组 `Learning` 是恢复前产品提示词的冻结副本；`GE` 直接调用恢复后的生产渲染器。这是完整提示词版本比较，同时变化数量与粒度说明，不能隔离“3–6”这一句的独立因果效果。

| 指标 | 恢复前 Learning | 完整 GE |
|---|---:|---:|
| 正式请求 | 22 | 22 |
| 格式和精确定位通过 | 22 | 22 |
| 整句一组（包括合理短问候） | 12 | 14 |
| 组数分布 | 1组×12，2组×8，3组×2 | 1组×14，2组×8 |
| 请求耗时中位数，已加载模型 | 829 ms | 828 ms |
| 因切开已识别单位而过滤的组 | 0 | 0 |

当前原生环境没有复现“GE 经常产生 3–6 组”的形态，也未显示粒度优势。三句预览用例“我期待见到你。”“你可以慢慢来。”“我会照顾你。”在两组、两轮均为整句一组。

两个 GPT-6 Luna 审查者对 14 个去重结果进行了隐藏组别的独立审查，认为多数对应在语义上成立；不能仅凭整句一组就认定短固定表达错误。两者均指出，GE 的长报告第二组把“核实数字”和“可能延期”合并，韩语回电例也由两部分合成整句，粒度较粗。一项礼貌回复的“me”是否可自然省略存在评分分歧；固定译文由实验提供，这不应直接归因于对齐提示词。AI 审查是参考判断，不是客观准确率。

原历史 GE 实验经过 Ollama，并使用独立的 28 词 system 消息和其 chat template；本次是产品内置 llama.cpp 路径。运行库、消息结构和实验环境不同，旧实验数字不能直接视为当前产品表现；也不能仅凭此断定 system 消息是差异原因。
